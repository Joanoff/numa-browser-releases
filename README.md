# Numa Browser — versions

Ce dépôt public est réservé aux fichiers installables et aux informations de mise à jour de Numa Browser. Le code source est conservé dans le dépôt privé [numa-browser](https://github.com/Joanoff/numa-browser).

Les installateurs seront publiés dans la section [Releases](https://github.com/Joanoff/numa-browser-releases/releases) lorsqu’une version prête à distribuer sera disponible.

Aucun installateur n’est publié pour le moment.
